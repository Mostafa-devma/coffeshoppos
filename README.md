# Coffee Shop POS

A touch-friendly point-of-sale for a coffee shop / café, in a single HTML file. No install, no server — open `index.html` in a browser.

## Features
- Order tabs for tables, takeaway and delivery orders
- Category cards and product grid with search
- Sales receipt panel: quantity stepper, notes, discount, split bill, send to kitchen, print
- Calculator keypad with change calculation
- Payment in LBP, USD (with exchange rate), card or Wish / OMT
- Sales history: date filters, search, reprint, void / restore, CSV export
- Statistics: revenue, receipts, average ticket, revenue by day and hour, top items, categories, payment methods, cashiers
- Menu and settings editor (⚙️ Menu)

## Files
- `index.html` — the current design
- `index_classic.html` — the earlier classic-style layout

## Data
Everything is saved in the browser's local storage on the device. Clearing the browser's site data erases orders and sales history.
